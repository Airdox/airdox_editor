# Reference Screenshots & Visual Lock Specification

This folder houses the visual reference definitions for the Rekordbox EDIT Mode:
- `01_rekordbox_edit_main_palette.png`: Main Edit view with open right-hand Palette, detail waveform, overview, and lower control blocks.
- `02_rekordbox_edit_main_fullwave.png`: Main Edit view with closed Palette (detail waveform dynamically expands horizontally).
- `03_rekordbox_edit_select_mode.png`: Active Selection state showing the transformed SELECT block with HALF, DOUBLE, CANCEL buttons and blue handle boundaries.

Visual Hierarchy & Constraints:
- Dark professional theme (#0c0c0e, #141416, #1c1d21, #28292e)
- 3-band / RGB / Blue waveform rendering with true audio spectral analysis
- Mathematically accurate beatgrid and bar positioning
- Precise selection box with blue handle accents and floating bar/beat/time counter
- Angled/chamfered polygonal tab shapes for BEAT SELECT, SELECT, EDIT, and BROWSER
